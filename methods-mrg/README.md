# 投资方法图谱

五位投资人的方法、计算和推理输入，以及逐图核验记录。侧栏可以切换图谱。点击节点或箭头查看详情和出处。

## 本地启动

在 Windows 上双击 `start.cmd`，或在项目目录的 PowerShell 中运行：

```powershell
.\start.cmd
```

打开 [127.0.0.1:5173](http://127.0.0.1:5173)，并保持启动窗口开启。脚本会使用已安装的项目依赖和本机 Node.js，也能识别 Codex 自带的 Node.js。

在新目录首次安装依赖时，使用 Node.js 22.12+ 和 pnpm 11：

```powershell
pnpm install
pnpm dev
```

打开终端显示的地址。每张图的地址可通过浏览器地址栏复制。

## 编辑

- 拖动节点调整位置，拖动画布平移，滚轮或左下控件缩放。
- 点击「编辑图谱」后可新增节点。把一个节点右侧的连接点拖到另一个节点左侧的连接点，即可新增有向边。
- 点击节点或连线，在右栏修改字段后保存。修改端点可使用右栏下拉菜单，也可拖动选中连线的端点。
- 改动按图保存在同一浏览器和本地地址下。「恢复核验版」仅清除当前图的改动。

## 检查与构建

```powershell
pnpm check
pnpm build
pnpm preview
```

构建产物位于 `dist/`。原文链接在详情及核验面板中。图中的公式与虚构示例用于说明所需输入，网页可在本地查看，原文链接需要网络。
